# Wordshift

Wordshift is a small, framework-free website that changes its title one word at a time. Each press of the **Next word** button cycles through a short list of words and updates the progress indicator.

## Built with

- HTML
- CSS
- JavaScript

## Run locally

Open `index.html` directly in a browser, or serve the folder with any static file server.

For example, with Python:

```bash
python3 -m http.server 3000
```

Then visit [http://localhost:3000](http://localhost:3000).

## Project files

- `index.html` — page structure and content
- `style.css` — responsive design and animations
- `script.js` — title-changing interaction
